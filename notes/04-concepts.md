# DreamDojo 核心概念解释

整理自学习过程中的问答，每个概念给出直觉理解和在 DreamDojo 中的具体作用。

---

## 1. Action-Conditioned 世界模型

**世界模型**：给定当前画面，预测未来画面的模型。

**普通世界模型的局限**：未来有无数种可能，模型只能生成"某种合理的未来"，但无法控制是哪一种。

**Action-Conditioned（动作条件化）**：显式告诉模型"现在执行什么动作"，模型基于此预测该动作对应的未来画面。

```
普通世界模型：  f_t  →  ??? 未来帧（不可控）
Action-conditioned：  f_t + action  →  确定性的未来帧
```

**在 DreamDojo 中的作用**：训练出的世界模型可以在虚拟环境里"模拟"机器人执行某个动作的结果，不需要真的操作机器人，用于策略评估和数据采集。

---

## 2. 扩散模型（Diffusion Model）

**目的**：生成图片（或视频）。去噪是手段，生成是目的。

**训练阶段**（学"去噪"）：
```
真实图片 → 逐步加噪声 → 纯噪声
模型学习：给定第 t 步的噪声图片，预测如何去掉一点噪声
```

**推理阶段**（用"去噪"来生成）：
```
从纯噪声出发 → 调用模型去噪（第1步）→ 调用模型去噪（第2步）→ ... → 清晰图片
（DreamDojo Teacher 模型需要 35 步）
```

**为什么选择这种方式**：直接让模型"从零画图"太难。但"去掉一点噪声"是个简单任务，容易学。把简单任务叠加 N 次，就实现了复杂的高质量生成。

**慢在哪里**：推理时需要调用模型 N 次（35次），每次都要完整前向传播，视频扩散模型每次还要处理整个帧序列，因此非常慢（DreamDojo Teacher 约 0.37 FPS）。

---

## 3. 注意力机制（Attention Mechanism）

**解决的问题**：序列中每个元素，应该关注其他哪些元素、关注多少？

**直觉例子**：翻译"我喜欢吃苹果"→"I like eating apples"。翻译"apples"时，模型需要重点关注"苹果"，几乎忽略"我"和"吃"。注意力机制自动学习这种"关注权重"。

**在视频生成中**：生成第 5 帧时，注意力机制决定第 5 帧应该参考哪些帧、参考多少。

### 双向注意力（Bidirectional Attention）

每个位置可以关注序列中**所有**其他位置，包括"未来"的帧：

```
生成 f_5 时：可以参考 f_1, f_2, f_3, f_4（过去）也可以参考 f_6, f_7...f_12（未来）
```

**导致生成长度固定的原因**：位置编码（告诉模型"这是第几帧"）在训练时是固定长度的（如12帧）。推理时无法生成超出该长度的序列，因为第13帧的位置编码没有被训练过。

**导致无法实时的原因**：必须等所有帧计算完才能输出（批处理），不能生成一帧输出一帧（流式输出）。

### 因果注意力（Causal Attention）

每个位置只能关注**过去**的帧，不能看未来：

```
生成 f_5 时：只能参考 f_1, f_2, f_3, f_4，不能看 f_6 及之后
```

**优势**：可以无限延伸——生成完 12 帧后，把这 12 帧作为新的历史上下文，继续生成下一批帧，理论上长度无限。且可以流式输出（生成一帧，立即输出一帧）。

---

## 4. 实时遥操作（Live Teleoperation）

**Teleoperation**：人在远端或 VR 中控制机器人运动，人做动作，机器人跟着做。

**Live（实时）的要求**：延迟需低于约 100ms，否则人会感觉"卡顿"，失去沉浸感和操控感。

**世界模型在遥操作中的作用**：不直接控制真实机器人，而是先在世界模型生成的虚拟视角里"预演"。人戴 VR 头盔，世界模型实时渲染机器人视角的画面，人根据画面操作，系统记录轨迹，再让真实机器人执行。

**双向注意力模型为何无法用于实时遥操作**：批处理方式——必须等一批帧（如12帧，约0.4秒）全部生成完才能显示，无法做到逐帧流式输出，延迟远超100ms。

**蒸馏后的 Student 模型**（因果自回归，4步去噪）：达到 10.81 FPS，可以做基本的实时预览（论文中在 RTX 5090 上实现了 live teleoperation 演示）。

---

## 5. 连续潜在动作（Continuous Latent Actions）

**核心思想**：不测量动作，而是从视频里**反推**动作。

如果相邻两帧之间发生了变化，那个变化就体现了动作。用 VAE（变分自编码器）把这个变化压缩成低维向量，这个向量就是 latent action。

**Continuous（连续）**：区别于离散动作（"左/右/停"这样的分类），32维连续向量可以表达细腻的运动幅度和方向，中间状态也能表示。

**LAM 的输入输出**：
```
输入：连续两帧 (f_t, f_{t+1})
输出：32维连续向量 â_t（latent action）
```

**训练方式**：自监督——标签来自数据本身（下一帧），不需要人工标注。

**用途**：作为世界模型的动作条件输入，让世界模型学习"给定动作，预测未来画面"。

---

## 6. 统一代理标签（Unified Surrogate Labels）

**问题背景**：不同数据源的动作格式完全不同——

| 数据源 | 动作格式 |
|--------|---------|
| 人类视频 | 无标签 |
| AgiBot 机器人 | 14维关节角度 |
| DROID 机器人 | 6维末端位移 |
| 人手（EgoDex）| MANO 参数 |

无法直接把这些异构数据放在一起训练同一个 action-conditioned 世界模型。

**Latent Action 作为统一代理标签**：对所有视频（无论来源），用同一个 LAM 提取 32 维向量。这个向量统一了所有数据源的动作表示，功能上代替（代理）了各种真实动作标签。

**"代理"的含义**：不是真实动作本身，但在"指导视频生成"这个功能上起到和真实动作相同的作用（论文 Table 2 验证：latent action 效果接近 GT action）。

---

## 7. 跨具身迁移（Cross-Embodiment Transfer）

**具身（Embodiment）**：身体的物理形态——人手有5根手指，机械臂是刚性关节，形态完全不同。

**跨具身的挑战**：在人类视频上学到的动作知识，能否迁移到机器人？直觉上很难，因为运动方式差异极大。

**为什么 Latent Action 具有跨具身性**：

VAE 的信息瓶颈（32维 + β=1e-6 的极小 KL 系数）强迫 LAM 只保留最本质的运动信息（方向、幅度、速度），而丢弃无关信息（外观、皮肤/金属纹理、关节数量）。运动的本质在不同具身之间是共通的——"向右移动"这个概念，对人手和机械臂都适用。

**结果**：人手向右移动和机械臂向右移动，提取出的 latent action 向量在向量空间里是相邻的（论文 Figure 3）。在人类视频上预训练的世界模型，可以迁移到机器人 Post-Training，并显著提升效果。

---

## 8. 因果自回归模型（Causal Autoregressive Model）

**自回归（Autoregressive）**：生成序列时，每个输出只依赖之前已经生成的内容，逐个生成。

**因果（Causal）**：生成当前帧时不能看未来帧——原因（动作+过去帧）产生结果（当前帧），时间方向明确。

```
因果自回归生成过程：
  生成 f_1（仅依赖条件帧）
  生成 f_2（依赖 f_1）
  生成 f_3（依赖 f_1, f_2）
  ...可以无限延伸
```

**优势**：
1. 可以无限延伸（不受训练时序列长度限制）
2. 可以流式输出（生成一帧即可输出一帧）
3. 支持实时应用

---

## 9. 蒸馏：为什么双向模型能蒸馏为因果模型

**知识蒸馏（Knowledge Distillation）的本质**：不是复制 Teacher 的结构，而是让 Student 学习 Teacher 的**输出分布**——对于同样的输入，Student 的输出要尽量和 Teacher 的输出一致。

**直觉类比**：一个"全知全能"的老师（可以看所有帧）可以训练一个"只看过去"的学生。老师不教学生"怎么看未来帧"，而是教学生"什么样的输出是好的"。学生通过大量对比（自己的输出 vs 老师的输出），逐渐学会在只看过去的情况下也能生成高质量结果。

**DreamDojo 的具体蒸馏流程**：

```
Warmup 阶段：
  Teacher 生成高质量视频（35步去噪）作为"正确答案"
  Student 用同样输入生成视频（4步去噪），学习回归到 Teacher 的输出
  此阶段 Student 的历史帧来自 Teacher（teacher forcing）

Distillation 阶段：
  Student 用自己生成的历史帧（更贴近实际推理情况）
  损失函数：KL 散度，衡量 Student 分布与 Teacher 分布的差距
  训练生成 13~49 帧，只在最后 13 帧计算损失（模拟长序列自回归）
```

**生成长度固定问题是否解决了**：✅ 完全解决。Student 是因果自回归模型，可以将已生成的帧作为新的上下文继续生成，理论上无限延伸。论文报告约 1 分钟视频质量稳定，之后开始退化。

## 10. DreamDojo 三阶段训练的目的

### 阶段 1：训练 LAM
- **输入**：任意视频（人类、机器人，无需标注）
- **目的**：学习从帧对中提取 32 维 latent action，作为后续阶段的动作标签
- **训练完后**：LAM 封存，只用作特征提取器

### 阶段 2：世界模型预训练（Human Video Pretraining）
- **输入**：44k 小时人类视频（In-lab:EgoDex:DreamDojo-HV = 1:2:10 采样比）+ LAM 提取的 latent action
- **注意**：世界模型预训练**只用人类视频**，机器人视频留给阶段 3
- **基础模型**：Cosmos-Predict2.5（NVIDIA 开源的视频扩散模型，DiT 架构）
- **目的**：让世界模型先从大量人类视频中学会"物理世界怎么运作"（重力、光影、物体交互、手部运动规律），同时学会以 latent action 为条件进行生成
- **为什么重要**：大量多样的人类数据提供了广泛的泛化能力，机器人数据太少、太单一，不足以支撑泛化

### 阶段 3：机器人 Post-Training
- **输入**：机器人视频 + 真实关节角度（相对动作 chunk，约 10Hz，序列长度 12）
- **不用 LAM**：Post-Training 完全使用真实关节角度，LAM 在这个阶段不参与
- **目的**：在预训练基础上，适配目标机器人的特定动作空间和视角
- **关键细节**：重新初始化 action MLP 第一层（因为从 32 维 latent action 换成了真实关节角度，维度和分布都不同）；最后一层在预训练时初始化为零，Post-Training 时保留

### 为什么可以跳过阶段 2（我们的复现策略）

NVIDIA 已开源 Cosmos-Predict2.5，它本身已经在大量视频数据上预训练，具备很强的视频生成能力。我们直接从它出发做 Post-Training，相当于跳过阶段 2。

**代价**：约 0.6 dB PSNR（论文 Table 3："w/o pretrain" 行 PSNR ≈ 20.3，完整版 ≈ 20.9）。对于验证 pipeline 可以接受。

---

## 复现策略总结

```
开源 Cosmos-Predict2.5 权重
          │
          │（跳过 44k 小时人类视频预训练）
          ▼
   LAM 训练（AgiBot 视频，自监督）
          │
          │ LAM 提取 latent action
          ▼
   Post-Training（AgiBot 视频 + 关节角度）
          │
          ▼
   Action-Conditioned 世界模型（可用于策略评估）
```

**数据来源**：AgiBot-World Alpha 替代 DreamDojo-HV（不开源）+ In-lab 数据（不开源）  
**性能预期**：接近论文 "w/o pretrain" 基线，PSNR ≈ 20.3 dB
