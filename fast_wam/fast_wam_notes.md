# Fast-WAM 精读笔记

> **论文**：*Fast-WAM: Do World Action Models Need Test-time Future Imagination?*
> **作者/机构**：Tianyuan Yuan, Zibin Dong, Yicheng Liu, Hang Zhao（IIIS 清华 + Galaxea AI），2026-03
> **链接**：arXiv 2603.16666 ｜ 项目页 https://yuantianyuan01.github.io/FastWAM/
>
> 一句话总结：论文用受控实验证明——**World Action Model（WAM）的收益主要来自"训练期的视频建模目标塑造了世界表征"，而不是"测试期显式想象未来"**；因此提出 Fast-WAM：训练保留视频协同训练，推理跳过未来生成，动作单次前向预测，190ms、比 imagine-then-execute 快 >4×。

---

## 一、研究背景

### 1. 两条技术路线
- **VLA（Vision-Language-Action）**：直接把视觉观测 + 语言指令映射到动作 `p(a|o,l)`。依赖 web 级图文预训练获得强语义先验，泛化好；但**基本基于静态图文数据，不显式建模"物理世界如何随动作演化"**。
- **WAM（World Action Model）**：在 VLA 之上引入"未来视觉观测"作为中间变量，把未来视觉预测与动作建模统一在一个生成框架里。直觉上，建模未来能捕捉物理动力学与任务相关的时序结构。

### 2. 现存 WAM 的通病：imagine-then-execute（先想象再执行）
- 范式：**先生成未来观测帧 → 再据此条件预测动作**。
- 形式化分解：`p(a_{1:H}|o,l) = ∫ p(v_{1:T}|o,l) · p(a_{1:H}|o,l,v_{1:T}) dv_{1:T}`（论文公式2）。
- 代价：测试时要做**迭代视频去噪**来合成未来帧，**延迟很大**（后文实测 imagine-then-execute 变体要 580ms / 810ms）。

### 3. 悬而未决的核心问题
WAM 的效果可能来自两个被**耦合在一起**的来源：
1. **训练期的视频预测目标**——帮助模型学到更强的物理先验 / 动作相关表征；
2. **推理期的显式未来生成**——为动作预测提供额外的"前瞻/foresight"。

现有 WAM 同时做这两件事，无法判断到底是哪一个在起作用。这正是本文要回答的问题：
> **WAM 在测试时真的需要"想象未来"吗？还是说收益主要来自训练时学会建模未来？**

---

## 二、核心思路 / 动机

- **关键 idea：解耦（decouple）**。把"训练期视频建模目标"和"推理期显式未来生成"这两个因素拆开单独考察。
- **核心假设**：如果世界建模的价值在于**训练期塑造更好的隐表征**，那么一个 WAM 应该能**保留这份收益、同时省掉测试时合成未来的成本**。
- 落到设计上：训练时照常用视频预测目标（video co-training）来塑造视觉骨干；推理时只用当前观测做**单次前向**得到隐世界表征 `z(o,l)`，直接解码动作，不再迭代生成未来帧。

三种 WAM 范式对照（论文 Figure 1）：
- **(A) Joint（联合建模）**：未来视频 token 与动作 token 在共享模型里**一起去噪**，动作生成全程与未来视频建模耦合。
- **(B) Causal / IDM（先视频后动作）**：先由当前观测+语言生成未来视频 token，再条件其上预测动作。
- **(C) Fast-WAM（本文）**：训练时保留视频协同训练；**推理时移除未来生成分支**，直接从世界隐表征单次前向预测动作。

---

## 三、创新点

1. **提出并研究一个 WAM 的基本问题**：收益主要来自训练期视频建模，还是来自推理期显式未来想象？（此前无人拆开验证。）
2. **提出 Fast-WAM 架构**：训练保留视频协同训练、推理跳过未来生成，实现**实时**动作预测。
   - 形式化：从 imagine-then-execute 的 `p(a|o,l)=∫p(v|o,l)p(a|o,l,v)dv`（公式2）→ 直接 `p_θ(a_{1:H}|o,l) = p_θ(a_{1:H}|z(o,l))`（公式3/4）。
   - **关键区别**：`z(o,l)` 由**单次前向编码**得到，而非在推理时采样/去噪未来观测 `v_{1:T}`。
3. **一套受控变体（controlled variants）**：在同一实现框架下复刻 imagine-then-execute 的主流设计（Joint / IDM），并额外做一个"去掉视频协同训练"的消融，从而**干净地分离两个因素**。
4. **结论性发现**：Fast-WAM 与 imagine-then-execute 变体表现相当，而**去掉视频协同训练会大幅掉点**——说明 WAM 的价值更多在训练目标本身，而非测试时的未来生成。

## 四、方法与架构细节（帮助理解的部分）

### 1. 问题形式化
- 标准 visuomotor 策略：`p(a_{1:H}|o,l)`（公式1）。
- WAM imagine-then-execute：引入未来观测 `v_{1:T}` 作为中间变量（公式2）。
- Fast-WAM：训练时保留视频协同训练塑造表征，推理时 `p_θ(a_{1:H}|o,l)`（公式3），并写成 `p_θ(a|z(o,l))`（公式4），`z(o,l)` 是视频骨干在当前上下文上单次前向产出的隐世界表征。

### 2. 骨干与模型结构（Figure 2a）
- **世界建模骨干**：预训练 **Wan2.2-5B 视频 Diffusion Transformer（DiT）**。
- **复用**其内置 **T5 文本编码器**（任务语言经 cross-attention 注入所有 token）和 **视频 VAE**（把视觉观测映射为 latent 视频 token）。
- **新增动作专家 DiT（action expert）**：与视频分支同架构但隐藏维更小 `d_a = 1024`，约 **1B 参数**；**全模型总计约 6B**。
- 组织为 **Mixture-of-Transformer（MoT）**：视频分支与动作分支之间**共享注意力**。

### 3. 三组 token
1. **干净首帧 latent token**：作为**共享锚点**（当前观测）。
2. **带噪未来视频 latent token**：**只在训练时**用于视频建模。
3. **动作 token**：由动作专家处理，用于动作 chunk 生成。

### 4. 结构化注意力掩码（Figure 2b，防未来泄漏的关键）
- 训练时：未来视频 token 在视频分支内**双向注意**，且可看干净首帧 token；动作 token 在动作分支内双向注意，也可看干净首帧 token。
- **关键约束**：动作 token **不能注意未来视频 token**；干净首帧 token 不注意任何其他 token。
  → 保证视频建模与动作预测都锚定在**同一视觉上下文**，同时**防止未来信息泄漏进动作分支**。
- 推理时：**整条未来视频分支被移除**，只保留干净首帧 latent，过一次视频骨干得到隐世界特征给动作专家。因为不再实例化带噪未来 token、也不做未来视频去噪，推理成本大幅低于标准 imagine-then-execute WAM。

### 5. 训练目标：联合流匹配（flow matching，公式5-9）
- 对目标变量 `y`（动作 chunk `a_{1:H}` 或未来视频 latent `z_{1:T}`）采样高斯噪声 `ε` 和时间步 `t`，构造插值样本 `y_t = (1-t)y + tε`（公式5）。
- 训练预测速度场，标准流匹配损失 `L_FM(y)`（公式6）。
- 动作预测损失 `L_act = L_FM(a_{1:H})`（公式7）；视频协同训练损失 `L_vid = L_FM(z_{1:T})`（公式8）。
- **总损失 `L = L_act + λ·L_vid`**（公式9），`λ` 平衡动作学习与视频协同训练。

### 6. 多相机（多视角）处理细节
- 实现里：**多个相机的图像先拼接（concatenate）成一张单图，再送入 VAE**。
- 注意：这只是简单的图像空间拼接，没有逐视角编码器或跨视角融合模块——"多视角"在本文不是重点机制。

## 五、实验与验证

### 1. Benchmark 与设置
- **LIBERO**：4 个套件（Spatial / Object / Goal / Long），每套件 500 演示 × 10 任务；全部训练 20k 步；40 任务共 2000 trials。
- **RoboTwin 2.0**：双臂协同操作，50+ 任务；多任务训练用 2500 条 clean 演示 + 25000 条重度场景随机化演示；训练 30k 步；每任务 100 trials，报告 clean 与 randomized。
- **真实世界**：Galaxea R1 Lite 平台**叠毛巾**（长程、可形变物体、需闭环精细操作）；采集 **60 小时**遥操作演示；训 30k 步；报告成功率 + 平均完成时间。

### 2. 实现细节
- 骨干 Wan2.2-5B（视频 DiT + 文本编码器 + VAE）；动作专家约 1B，总 6B。
- 动作 horizon `H=32`；视频时间下采样 4×，每 chunk 9 帧。
- 视频与动作分支同用流匹配；`t` 用 logit-normal 噪声调度。
- **推理 10 步去噪，CFG=1.0**；AdamW，lr 1e-4，weight decay 0.01，cosine 退火；混合精度、梯度裁剪 1.0。
- 延迟统一在单张 **NVIDIA RTX 5090D V2 32GB** 上测。
- Fast-WAM-Joint：允许视频/动作 token 互相注意；Fast-WAM-IDM：对 GT 视频 token 以 p=0.5 加噪增强。

### 3. 主结果
- **RoboTwin（表1，平均）**：Fast-WAM **91.8%**（**无 embodied 预训练**），超过所有无预训练基线，且**超过带预训练的 Motus（87.8%）**、逼近带预训练的 LingBot-VA（92.2%）。
- **LIBERO（表2，平均）**：Fast-WAM **97.6%**（无预训练），超过强 VLA 基线 π0.5（96.9%），逼近 LingBot-VA（98.5%）、Motus（97.7%）。
- 结论：Fast-WAM 无需具身预训练即可跨仿真基准稳定有效。

### 4. 受控对比 + 消融（核心验证）
在两个仿真基准上模式一致：
- **Fast-WAM ≈ imagine-then-execute 变体**：
  - RoboTwin：Fast-WAM 91.8% vs. Joint 90.6% vs. IDM 91.3%（三者接近）。
  - LIBERO：Fast-WAM 97.6% vs. Joint 98.5% vs. IDM 98.0%。
- **去掉视频协同训练 → 大幅掉点**：
  - RoboTwin：**降到 83.8%**（相对三个含视频协同训练的变体有明显差距）。
  - LIBERO：**降到 93.5%**（Spatial、Long 子集退化尤其明显）。
  - 真实叠毛巾：**成功率崩到约 10%**，且完成时间最长。
- **结论**：去掉视频协同训练造成的差距，**远大于** Fast-WAM 与 imagine-then-execute 变体之间的差距 → **视频协同训练（训练期目标）是主导因素，测试时未来想象贡献有限**。

### 5. 效率
- **Fast-WAM 190ms**，比 imagine-then-execute 快 **>4×**。
- 延迟对比（图4右）：π0.5 180ms、Fast-WAM 190ms、Fast-WAM w/o video co-train 190ms、**Joint 580ms、IDM 810ms**。
- 真实叠毛巾（图4左）：含视频协同训练的所有 Fast-WAM 变体都**大幅超过无预训练的 π0.5**，说明 WAM 式视频协同训练即便没有具身预训练也带来强数据效率。

### 6. 结论与 future work
- 视频预测在 WAM 里的主要价值 **在训练期塑造 world-grounded 表征**，而非测试期生成未来观测。
- 未来方向：研究**更大规模预训练数据**与**模型规模扩展**对该设计的影响。

## 六、拓展解读：在 WAM 上用 LAM（潜在动作模型）预训练

> 这一节是从"能否/如何在 WAM 上用 LAM 做预训练"的角度，对本文做延伸解读——这不是论文本身的内容，而是基于其结论的推演。

### 1. 先厘清一个事实
- **Fast-WAM 本身并不做 LAM 预训练**，也**没有具身预训练**。它用**真实动作标签** `a_{1:H}` 直接做流匹配（公式7）+ 未来视频 latent 协同训练（公式8）。
- 所以严格说，这不是一篇 LAM-pretrain 论文。但它的结论恰好为"LAM 预训练 WAM"这条路线提供了**理论依据**，也点出了它的直接范本与风险。

### 2. 为什么本文结论支持"LAM 预训练"
- 本文的受控实验证明：**WAM 的收益来自"训练期用某种自监督目标塑造世界/动作表征"，而不是测试时 rollout 未来。**
- **LAM 预训练正是这样一种"训练期表征塑造"目标**：它从**无动作标签的视频**里学出 latent action，用自监督方式塑造动作相关表征。
- 推论：与其把算力花在测试时想象未来（Fast-WAM 已证明其收益有限），不如把算力投在**训练期的表征学习**上——无论是视频协同训练，还是 LAM 预训练。二者本质是同一类"训练期目标"。

### 3. Fast-WAM 架构如何接入 LAM 预训练
Fast-WAM 现在的结构是「预训练视频 DiT + 动作专家 DiT（MoT），动作专家直接预测**真实动作**」。要加入 LAM 预训练，可按 **Genie / LAPA / Motus 的经典三步配方**改造：

1. **训练一个 LAM**：用逆动力学（Inverse Dynamics）从相邻视频帧 `(f_t, f_{t+1})` 学出**离散或连续的 latent action `z`**。
2. **无动作标签视频预训练**：用大规模无标签视频（含人类操作视频等）预训练「视频 DiT + 动作专家」，让动作专家**预测 latent action `z`**（而不是真实机器人动作）——从而在没有动作标注的海量数据上塑造表征。
3. **少量真实动作微调**：用小规模带真实动作标签的机器人数据，学一个从 `z` 到真实动作 `a` 的**解码头**（或直接微调动作专家）。

**Fast-WAM 缺的正是第 ①② 步**——它直接从第 ③ 步（真实动作监督）起步。把 ①② 补上，就是"在 WAM 上用 LAM 预训练"的自然实现。

### 4. 相关工作指路
- **Motus [5]**（*Motus: A unified latent action world model*, arXiv 2512.13030）：**LAM + WAM 的直接范本**，统一潜在动作世界模型。想做这个方向应精读它。
- **VPP [34]**：用视频扩散模型抽取的预测性视觉表征来条件策略。
- **UVA [35]**：联合建模视频与动作，测试时跳过视频解码以加速。
- VPP / UVA 与 Fast-WAM 的"省掉测试时视频合成"思路一脉相承。

### 5. 反面参考点 / 风险提示（重要）
- **Fast-WAM 无任何预训练（RoboTwin 91.8%）反而超过了带预训练的 Motus（87.8%）。**
- 这提醒：**当前的 latent-action 预训练，实际收益未必优于"简单的视频协同训练 + 真实动作监督"。**
- 因此在 WAM 上投入 LAM 预训练前，应先做对照实验验证其增益是否真的超过 Fast-WAM 式的视频协同训练基线，避免为预训练付出算力却收益有限。
- 这也呼应论文的 future work：LAM 预训练的价值可能要在**更大规模预训练数据 + 模型扩展**下才充分显现。
